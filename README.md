# Weather App

A weather app with a live animated canvas background that shifts color, gradient, and particle effects to match the current conditions — sun for clear skies, falling rain, drifting snow, twinkling stars at night, and the occasional lightning flash during storms.

## Features

- 🔍 Search weather for any city worldwide
- 🌡️ Current temperature, "feels like," humidity, wind speed, and UV index
- 🌅 Sunrise, sunset, and precipitation
- 📅 5-day forecast strip
- 🎨 Animated background that reacts to weather type and time of day
- No API key required

## Tech Stack

- Vanilla HTML, CSS, and JavaScript — no frameworks, no build step
- [Open-Meteo](https://open-meteo.com) Geocoding API + Forecast API for weather data
